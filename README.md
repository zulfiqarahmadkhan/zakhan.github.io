## Use this template for your own site

A simple academic website (About, Publications, CV) with a day/night theme.
No build step and no coding needed. Free to reuse; a link back is appreciated.

1. **Fork** this repository and rename it to `<your-username>.github.io`.
2. **Edit the two files in `data/`**:
   - `profile.json`: name, position, bio, links, metrics, education, experience, awards
   - `publications.json`: your papers
3. **Replace** `assets/photo.jpg` and the PDFs in `files/` with your own.
4. In **Settings → Pages**, deploy from branch `main` / `(root)`.

To preview locally, run `python -m http.server 8080` in the folder and open <http://127.0.0.1:8080>.
